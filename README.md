# Simple LED PCB Design using KiCad

## Overview

This project demonstrates the complete PCB design workflow using KiCad.

The circuit consists of:
- Battery Connector
- 270 Ω Resistor
- LED

The resistor limits the current through the LED to ensure safe operation.

---

## Features

- Single-layer PCB
- Through-hole components
- Beginner-friendly design
- Compact layout
- 3D model visualization

---

## Components

| Component | Value |
|-----------|---------|
| R1 | 270 Ω |
| D1 | LED |
| BT1 | Battery Connector |
